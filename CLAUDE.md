# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm ci              # Install dependencies
npm test            # Run all checks (lint, TOC validation, recipe completeness)
npm run lint:md     # Markdown lint only
npm run toc         # Regenerate README.md TOC (run after heading changes)
npm run toc:check   # Validate TOC is current (used by CI)
npm run recipes:check  # Validate all recipes in proteins/ and holidays/ have ## Feedback & Ratings
```

Always run `npm ci && npm test` before committing or suggesting a PR.

## Architecture

This is a Markdown-only knowledge base — no application code. The "build system" is Node.js scripts
that validate content quality.

**Content layout:**

- `proteins/` and `holidays/` — recipes, each subfolder has a `README.md` index linking to recipes
- `cooks/` — real-world cook logs (what actually happened), dated `YYYY-MM-DD_description.md`
- `techniques/` — reusable technique write-ups referenced by recipes
- `equipment/` — smoker-specific notes (all recipes assume the **Pit Boss Austin XL**)
- `marinades/` — canonical marinade bases

**Two-template system:** `TEMPLATE_RECIPE.md` for idealized recipes; `TEMPLATE_COOK_LOG.md` for real-world
logs. Keep these separate — recipes describe the ideal approach, cook logs capture what actually happened.

**CI checks** (`npm test` runs all three):

1. `markdownlint-cli2` — style lint; line length 120 (tables exempt)
2. `scripts/check_toc.mjs` — fails if README.md TOC is stale
3. `scripts/check_recipes_have_feedback.mjs` — fails if any recipe under `proteins/` or `holidays/`
   is missing `## Feedback & Ratings`

The `README.md` TOC is generated by doctoc and bounded by doctoc markers — never hand-edit the generated section.

## Content Guidelines

- Prefer "cook to temperature, not time" — include target internal temps and doneness cues; call times estimates.
- All recipes target the **Pit Boss Austin XL**: right side runs hotter; thick cuts go right, thin cuts
  left, poultry legs/thighs toward the right.
- Unicode typography is fine (→, °F, ½, en dashes). Avoid mojibake from copy/paste.
- When adding a recipe: copy `TEMPLATE_RECIPE.md`, place under the correct `proteins/` or `holidays/`
  subfolder, and update the relevant folder `README.md` index.
- If tradeoffs exist (foil vs. butcher paper, sauce timing), note them explicitly.
